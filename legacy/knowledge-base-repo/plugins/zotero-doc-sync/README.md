# Zotero Doc Sync

Obsidian 桌面插件，使用独立定时器刷新 Zotero 文献和处理知识任务。

安装时将本目录复制为：

```text
<vault>/.obsidian/plugins/zotero-doc-sync/
```

插件仅保存上次健康检查时间。Zotero collection、本机路径和其他运行参数均由 `system/zotero-sync/config.json` 与 `system/knowledge/config.json` 提供。

普通 PDF 同步最多 5 分钟，不执行联网 SI/JIF 补全。补全使用独立缓存和锁，由每小时的辅助任务运行。Forge 总预算为 30 分钟，插件外层 35 分钟仅用于异常兜底。

## 自动调度

- 每 3 小时独立检查 Zotero 新增文献；插件启动时仍先同步一次，手动同步随时可用。Forge、逐段精读或健康检查运行期间仍可刷新 PDF 和来源清单。同一轮同步未结束时跳过重叠触发，避免重复同步。
- 知识处理器每 60 秒检查一次，仅在空闲时扫描来源并串行处理下一条任务。生成期间同步到的新文献会保留在来源清单中，待处理器空闲后重新扫描入队；不并发修改生成队列。
- 状态栏分别显示 Zotero 最近同步时间/失败原因和知识任务进度；后台同步失败不会被“知识处理完成”覆盖，也不会反复弹窗。Zotero 暂时离线时，已有本地文献的任务仍可继续。
- 手动同步命令仍先同步，再尝试处理下一条知识任务；生成正忙时只同步，不启动第二个生成任务。
- 自动刷新要求插件已启用、Obsidian 与 Zotero 正在运行且 Mac 未睡眠。安装插件文件并不等于启用插件。

“整合当前已完成人工审核的知识笔记”只整合，不授予审核。请先在对话插件中完成审核并明确接受剩余警告；修改正文后需要重新审核。新增“只校验并修复当前 Forge 草稿”，复用已保存计划，不重新分析全文。

“查看知识关联与整理线索”生成并打开本地关联报告，列出断链、重名链接、重复声明标记和跨已审核来源的待整理概念。它不调用模型，也不自动修改科学内容；论文生成暂停时仍可使用。审核后整合先在候选工作区修改规范知识页，再校验证据并提交，来源笔记正文保持原样。

## 证据对比与知识维护

在命令面板运行以下命令，均只生成并打开本地报告，最多等待 30 秒；论文生成暂停时仍可使用：

| 命令 | 操作 | 报告 |
|---|---|---|
| 生成跨论文证据对比 | 在弹窗输入比较问题；空输入不运行。当前主论文/实验笔记可作为关联来源 | `system/reports/evidence-comparison.md` |
| 查看同义概念整理建议 | 检查用户显式声明的名称映射，不自动合并或删除页面 | `system/reports/concept-maintenance.md` |
| 更新研究问题整理报告 | 列出相关已审核证据、过期来源和待补证据 | `system/reports/research-question-maintenance.md` |

报告保留各源声明、适用条件、页码及审核状态。草稿只供线索；至少两项独立主来源当前审核有效，才具备正式跨来源对比的整合资格。支持或矛盾关系仍需审阅证据与条件，不能根据关键词相近判断。

显式名称映射由用户维护在 `system/knowledge/concept-aliases.json` 或规范概念页的 `aliases` 属性中。报告不修改规范页、不授予审核，也不调用摄取、健康检查或科学整合。完整契约见 vault 的 `system/workflows/knowledge-maintenance.md`。

## 可选逐段精读

常规 Forge Paper Note 草稿会包含两个 Obsidian 复选属性：

- `paragraph_reading`：人工确认这篇论文值得逐段精读；
- `paragraph_reading_figures`：兼容旧笔记的附加裁图开关；当前单元直接相关的图、表、公式裁图始终属于精读流程。

在打开的论文笔记中勾选 `paragraph_reading` 后，插件会自动启动精读并立即显示处理
进度。也可以在命令面板运行“开始或继续当前论文的交互式全文精读”。
插件调用本地 `paper-intensive-reading` skill，把交互日志写到
`wiki/papers/close-reading/`。原文以可搜索文本逐段配对翻译，不显示重复的“原文”“翻译”标签；相关图像才从 PDF 裁到
论文专属的 `images/<论文>/intensive-reading/Uxx/`，并插在对应段落翻译后。每次只
推进一个人机交互阶段。

填写“用户初始理解”后，点击状态栏中的“提交 Uxx 初始理解”按钮；仅填写文字不会
自动推进。提交、继续、提示、解释和合并时均显示后台阶段、已用时间和输出间隔；未知比例使用不定进度条。还可从命令
面板运行“提交当前精读单元的初始理解”“获取当前精读单元的分级提示”或“查看当前
精读单元的专家解释”。

旧版日志若已停在等待初始理解阶段，状态栏按钮会先显示“更新 Uxx 精读格式”；点击后
只完成原位迁移并保持当前阶段不变。迁移后阅读新版无标签段落对，再填写并提交。

精读日志仅是辅助证据，不能直接执行“审核并整合”。只有单元评分至少 6/8 且无重大
事实错误后，才能运行“合并当前已验证精读单元”。该命令只把验证/修正/非重复增量
连同 PDF 页码写回主笔记；之后仍需对主笔记执行原有审核与整合。
